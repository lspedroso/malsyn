# MALSYN — Engenharia Digital & Estratégia

Website oficial da **MALSYN**, estúdio de engenharia de software e desenvolvimento web moderno. Criamos interfaces de alta fidelidade, landing pages de alta conversão, portais corporativos e soluções digitais sob medida.

---

## 🚀 Tecnologias Utilizadas

- **React 18** (Vite)
- **React Router DOM v6** (Navegação SPA fluida)
- **Vanilla CSS** com Design System próprio (Dark Mode refinado, tokens de design, glassmorphism e micro-animações)
- **SVG vetoriais otimizados** para branding e gráficos de precisão

---

## 📁 Estrutura do Projeto

```
site-malsyn/
├── assets/             # Ícones e marcas oficiais em vetor
├── public/
├── src/
│   ├── components/     # Componentes modulares (Navbar, Hero, Sobre, Pilares, etc.)
│   ├── pages/          # Páginas (Home, Planos, Projetos)
│   ├── App.jsx         # Roteamento e estrutura principal
│   ├── index.css       # Design system completo e responsividade
│   └── main.jsx        # Ponto de entrada da aplicação
├── index.html          # Shell HTML com meta tags e tipografia
├── package.json        # Dependências e scripts
└── vite.config.js      # Configuração do Vite
```

---

## 🛠️ Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/lspedroso/malsyn.git
   cd malsyn
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gere o build de produção:**
   ```bash
   npm run build
   ```
